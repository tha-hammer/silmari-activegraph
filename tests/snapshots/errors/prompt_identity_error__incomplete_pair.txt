PromptIdentityError: incomplete prompt identity metadata

What failed:
  A fixture provider received exactly one of `prompt_hash` and `deterministic`; these values are one atomic identity pair.

Why:
  The runtime and fixture providers must name identical prompt bytes before any provider call or fixture I/O; otherwise recording and offline replay would silently address different files.

How to fix:
  This is a framework bug, not a problem with your code.
  Please file an issue and include the framework version, the
  internal error location, and the full message above:
      https://github.com/yoheinakajima/activegraph/issues/new

    framework version:   activegraph 1.10.0
    internal location:   activegraph.llm.recorded:_resolve_prompt_identity
